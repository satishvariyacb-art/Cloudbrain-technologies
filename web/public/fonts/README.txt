CloudBrain Website Custom Font Directory
========================================

Place your font files in this folder with the exact filenames listed below.
Supported formats: .woff2 (recommended), .ttf, .otf, .woff

1. MAIN SANS-SERIF FONT FAMILY (cbsans):
----------------------------------------
- cbsans-Thin.woff2       (Font Weight: 100)
- cbsans-Light.woff2      (Font Weight: 300)
- cbsans-Regular.woff2    (Font Weight: 400)
- cbsans-Medium.woff2     (Font Weight: 500)
- cbsans-SemiBold.woff2   (Font Weight: 600)
- cbsans-Bold.woff2       (Font Weight: 700)
- cbsans-ExtraBold.woff2  (Font Weight: 800)

2. TYPEWRITER / HERO FONT FAMILY (cbsans-Typewriter):
-----------------------------------------------------
- cbsans-Typewriter-Regular.woff2 (Font Weight: 400/600)

Note: Once you place these font files here, the whole website will automatically load and apply them instantly across all components!
